# Living NPC Demo Project

Unity 2022.3 LTS-compatible starter scene.

## Start

From the repository root:

```bash
docker compose up --build
python scripts/run_demo.py
```

Then open this `Demo` folder in Unity and load `Assets/Scenes/LivingNpcDemo.unity`.

The backend can be pointed to a real OpenAI-compatible LLM or local Ollama without changing the Unity scripts.
