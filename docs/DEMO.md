# 5–10 minute demo

1. Create a world.
2. Create Alice and Boris with conflicting values.
3. Record an event where the player helps Alice.
4. Tick the world while no player action occurs.
5. Start NPC ↔ NPC dialogue.
6. Inspect Alice's memory and relationship state.
7. Record a betrayal event.
8. Continue simulation.
9. Show changed trust/resentment and persistent memory.

The point of the demo is not to claim consciousness. The point is to show continuity:
past events alter future dialogue and behavior.
