# Living NPC Platform v0.2

## What changed

- PostgreSQL + pgvector persistence adapter for worlds, NPC snapshots and memory events.
- Redis Pub/Sub event bus with an in-memory bus retained for local/test operation.
- Optional FAISS vector store with deterministic fallback when FAISS is unavailable.
- Real OpenAI-compatible LLM gateway; Ollama works through the same protocol. Mock remains the default.
- Persistent world boundary: `WorldPersistence` saves world/NPC state without changing the `World` API.
- WebSocket streaming at `/ws/worlds/{world_id}` using the same event bus.
- Unity SDK expanded with `NpcController` and autonomous tick demo.

## Compatibility

Existing v0.1 calls such as `World("demo")`, `world.tick_once()`, `NPC.observe()` and `LLMProvider.generate()` remain valid.

## Production path

Set `POSTGRES_ENABLED=true`, `REDIS_ENABLED=true`, and `LLM_PROVIDER=openai-compatible` or `ollama`. PostgreSQL uses pgvector for future semantic retrieval; the included FAISS adapter is useful for local/offline vector search.

The 0.5-second world tick is a configurable target, not a hard real-time guarantee. The runtime compensates for work duration and reports events through the bus.

The LLM gateway is a real network integration when configured; no API key is stored in source code.
